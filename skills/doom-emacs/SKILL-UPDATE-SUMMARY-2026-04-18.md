## 🚀 快速开始指南

### 1. 基础安装
```bash
# 安装Doom Emacs
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.config/emacs
~/.config/emacs/bin/doom install

# 启用doom-emacs技能
# 在Doom配置中启用相关模块
```

### 2. LSP Advanced训练
```bash
# 创建训练目录
mkdir -p ~/code/openclaw-lsp-training
cd ~/code/openclaw-lsp-training

# 获取训练文件
# (训练文件已在本更新中创建)

# 启动训练
./start-training.sh

# 按顺序完成12题训练
# 或挑战最终考核
make final_challenge
```

### 3. 技能认证
```bash
# 完成训练后获取认证
# 1. 完成所有12题训练
# 2. 通过最终考核
# 3. 在实际项目中应用技能
# 4. 获取OpenClaw LSP Advanced Master认证
```
